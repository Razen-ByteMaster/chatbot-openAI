# Chatbot-V1 with GPT

This Python script allows you to interact with OpenAI's GPT model in a conversational manner. By leveraging the `openai` Python library, it provides a simple interface where the user can enter prompts, and receive responses generated by GPT-3.5. The script continues to prompt the user until a "quit", "exit", or "bye" command is entered.

## Features

- Communicates with OpenAI’s GPT-3.5 model using the `openai.ChatCompletion.create` method.
- Allows continuous interaction with GPT-3.5 through a simple terminal interface.
- Exits the chat session when the user types "quit", "exit", or "bye".
- Simple and easy to use for experimenting with the OpenAI API.

## Requirements

- Python 3.x
- OpenAI API key (replace the empty string in `openai.api_key` with your key).

## Installation

1. Install the `openai` Python package:

   ```bash
   pip install openai
   ```

2. Add your OpenAI API key to the `openai.api_key` field in the code.

## Usage

To start the chatbot, run the script in your terminal:

```bash
python chat_with_gpt.py
```

Once the script is running, you can interact with GPT by typing messages. Type `quit`, `exit`, or `bye` to end the chat.

# Chatbot-V2 with GUI

This Python script creates a simple graphical user interface (GUI) chatbot using `tkinter` for interacting with OpenAI's GPT-3.5 model. It allows users to input prompts through a text entry field, and it displays responses from GPT-3.5 in a scrollable chat window. The application continues running until the user types "quit", "exit", or "bye".

## Features

- **Graphical User Interface**: Built with `tkinter` to provide an intuitive and user-friendly interface.
- **Chat with GPT-3.5**: Communicates with OpenAI’s GPT-3.5 model using the `openai.ChatCompletion.create` method.
- **Error Handling**: Displays an error message in case of issues with the OpenAI API or any other error.
- **Continuous Chat**: Allows continuous conversation with the AI until the user types a termination command.
- **Responsive Layout**: The chat window and input field are designed to automatically adjust to window resizing.

## Requirements

- Python 3.x
- OpenAI API key (replace the empty string in `openai.api_key` with your API key).
- `tkinter` (typically included with Python, but can be installed separately if necessary).
- `openai` Python packages

## Installation

1. Install the required dependencies:

   ```bash
   pip install openai
   ```

2. Add your OpenAI API key in the line `openai.api_key = ""`.

## Usage

To start the chatbot, run the script in your terminal:

```bash
python chatbot_gui.py
```

Once the script is running, you can interact with GPT-3.5 by typing your message in the input field and pressing "Send" or hitting the Enter key. The chat window will display your messages and the chatbot’s responses. Type `quit`, `exit`, or `bye` to close the application.
